# 포커 (텍사스 홀덤) 🃏

컴퓨터 세 명과 겨루는 혼자 하는 텍사스 홀덤입니다. 서버 없이 `index.html` 만 열면 돌아갑니다. **게임용 칩**이라 진짜 돈과 아무 상관이 없습니다.

- 조작: 아래 버튼(폴드 · 체크/콜 · 레이즈). 레이즈를 누르면 막대와 최소·½ 팟·팟·올인 버튼으로 금액을 고른 뒤 확정합니다. 키보드: `F` 폴드, `C` 체크/콜, `R` 레이즈, `1~4` 금액, `Enter` 확정, `N` 다음 판, `P` 일시정지, `M` 소리.
- 규칙과 컴퓨터는 `logic.js`(DOM 없음), 화면·소리·입력은 `game.js`. 시험: `node --test`.

## 규칙
- 4명(나 + 민수·지아·도윤), 시작 칩 1000. 개인 카드 2장, 공용 카드는 플랍 3장 → 턴 1장 → 리버 1장. 베팅은 프리플랍 · 플랍 · 턴 · 리버 네 번.
- 노리밋 방식: 레이즈는 직전 레이즈 크기 이상(올인은 그보다 작아도 가능), 올인 가능. 모두 폴드하면 남은 사람이 바로 팟을 가져가고 카드는 공개하지 않습니다.
- 큰 블라인드 차례에 선택권(체크/레이즈), 둘만 남으면(헤즈업) 딜러가 작은 블라인드를 내고 프리플랍에는 먼저, 이후에는 나중에 행동합니다.
- 올인과 **사이드 팟**: 칩이 모자란 사람은 자기가 건 만큼의 팟만 딸 수 있습니다. 남에게 안 받은 초과분은 돌려받습니다. 동점이면 팟을 나누고 남는 한 칩은 딜러 왼쪽 첫 사람에게.
- 족보: 하이카드 < 원페어 < 투페어 < 트리플 < 스트레이트(A-2-3-4-5가 가장 낮음) < 플러시 < 풀하우스 < 포카드 < 스트레이트 플러시(로열 포함). 7장 중 최고의 5장으로 비교하고 무늬는 승부에 영향이 없습니다.
- 6판마다 블라인드가 오릅니다(10/20 → 15/30 → 25/50 → 50/100 …). 칩이 0이 되면 탈락, 내 칩이 0이면 끝, 세 명을 모두 탈락시키면 승리입니다.
- 컴퓨터는 카드 무작위 시뮬레이션으로 이길 확률을 계산하고(최대 상대 수에 맞춤), 팟 오즈와 성격(신중한 민수 · 공격적인 지아 · 많이 따라오는 도윤)에 따라 폴드·콜·레이즈·가끔 허세를 부립니다.

## 확인하지 못한 값
- 규칙은 일반적인 텍사스 홀덤을 따랐고, 컴퓨터의 판단 기준(확률 임계값, 성격 수치, 베팅 크기, 허세 확률)과 블라인드 표, 시작 칩 1000, 6판마다 상승은 제가 정한 값입니다. 실제 프로 선수 수준이 아닙니다.
- 짧은 올인이 이미 행동한 사람에게 다시 레이즈할 권리를 주는지 같은 세부 규칙은 단순하게 처리했습니다(짧은 올인은 최소 레이즈를 바꾸지 않고, 이미 행동한 사람도 콜은 해야 하지만 레이즈 권리 제한은 두지 않음).
- 온라인 대전은 없습니다(혼자 컴퓨터와). 그림·소리는 직접 그린/합성한 것입니다.
